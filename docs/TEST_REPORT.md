## 4. PDF 与打印版式

- 单条记录：1 页 A4 纵向，示值和测量时间按 I1-1 至 I3-3 分别占独立行；
- 批量 100 条：100 页 A4，本机生成约 0.18 秒；
- 周统计：1 页 A4 横向，固定显示周一至周日 7 个日期列，各示值和测量时间逐项分行；
- 空白表：1 页 A4，与正式单日表使用相同的逐项行结构；
- SOP：4 页 A4，中文字体、页码和页脚正常；
- 所有 PDF 均实际渲染为 PNG 并目视检查，无乱码、黑块、溢出或裁切；
- 待提交/已提交带“未复核”水印，已作废带“已作废”水印。

客户最终打印签认仍需在目标打印机和纸质表格上完成。

以上是本机高配置性能，不是 4 核/4 GB 客户的正式性能结论。

## 6. 浏览器联调

### 主流程

- 管理员、检验人员、复核确认人员登录与首次改密；
- 低置信字段核对、记录提交、U003 电子签名复核；
- 管理员主数据、模板、账号、审计和运行状态；
- 合成 U001/F001 视频真实上传、排队、分析完成、九项读数与识别帧；
- 刷新页面后记录仍可读取；
- 新增“通知中心”和服务端审计分页；上传进度与失败原因继续在上传页/任务页呈现；
- 记录详情显示固定判定时间、规则版本和容差。

### 响应式与可访问性

- 检验、复核和管理员共 18 个路由检查通过；
- 390×844 移动端所有代表路由横向溢出为 0；
- 768×1024 平板端无横向溢出；
- 页面不产生外部请求；
- 无未处理 `pageerror` 或失败请求；
- 表单控件通过 `label/for`、包裹标签或 `aria-label` 获得程序化名称；
- 图片均有 `alt`，按钮均有可访问名称。
