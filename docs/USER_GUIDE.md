# 用户手册

## 1. 登录

浏览器打开系统内网地址，使用管理员分配的账号和口令登录。全新安装不提供固定默认口令。Docker 部署由管理员在 `.env` 的
`INITIAL_PASSWORD` 中设置一次性口令；非容器方式未配置时，系统会生成随机口令并
写入数据目录下的 `initial-password.txt`。首次登录必须改为不少于 8 位、同时包含
字母和数字的私人密码。完成全部初始账号改密后应删除该文件。连续 5 次口令错误会
锁定账号 10 分钟；未知账号登录也受来源频率限制。30 分钟无操作自动退出。

## 2. 检验人员：二维码准备

检验人员可从左侧导航进入“二维码”。复核确认人员仅可查看设备二维码，没有个人二维码：

1. 检验人员在“我的人员二维码”中预览身份卡，并下载 SVG 或 PNG。二维码内容仅包含
   人员账号，不包含姓名或口令。
2. 检验人员在天平设备卡区域输入天平编号或唯一号，点击“查询”，核对大号设备编号
   和唯一号后下载 SVG 或 PNG。
3. 点击“打印卡片”可按实际尺寸打印。二维码本体建议不小于 40 mm × 40 mm；
   设备卡应平整贴在天平正面或侧面，不遮挡显示屏、水平泡和按键。
4. 人员卡与设备卡可以同时出现在视频画面中。设备卡长期可见是正常场景；人员卡由
   本人出示至少 2 秒即可。

管理员还可以在“账号与角色”列表中为指定人员导出身份卡。

## 3. 检验人员：上传视频

1. 选择“上传视频”。
2. 选择 MP4 或 MOV 文件，文件不超过 500 MB，编码 H.264，音频 AAC。
3. 核对文件名、大小与拍摄开始日期时间。视频缺少元数据时必须人工确认。
4. 开始上传。网络中断后重新进入页面，系统从服务端确认的偏移继续传输。
5. 上传成功后任务进入“排队中”；可查看队列位置。
6. 仅“排队中”的任务可由管理员取消；失败任务可重试。
7. 上传进度、取消操作和失败原因在“上传”页查看；任务排队、重试、人工处理和
   完成记录在“我的分析任务”页查看。同一拍摄日期或天平已有记录时会在上传前提示，
   但不会覆盖既有记录。

固定支架拍摄要求：

- 开头依次清晰展示人员二维码卡和设备二维码卡，各停留至少 2 秒；
- 画面同时覆盖显示屏与称重仓；
- 每次稳定读数停留不少于 3 秒；
- 双量程天平先完成高量程 3 次，再切换量程完成低量程 6 次。

本版本不使用语音识别，无需口述或录入语音。

## 4. 检验人员：核对并提交

1. 在“我的任务/待提交记录”打开记录。
2. 核对人员卡、设备卡、9 个读数、读数时间与识别截图。
3. 低置信、缺次、不稳定项目以醒目状态显示。
4. 修正读数时填写理由；系统记录修改前后值、操作人与时间，并实时重算结论。
5. 根据现场观察确认清洁、水平调节、内部校正是否通过，并确认砝码盒编号与备注。
6. 点击“一键提交”。提交即构成电子确认。
7. 提交后仅备注可改；复核确认后全部字段锁定。

不通过记录也需要提交并复核，作为异常记录归档。“不通过”不是系统故障，
不得通过人工改判绕过；只能修正识别错误的原始读数并重新复算。

## 5. 复核确认人员

1. 打开“待复核”。
2. 查看视频、识别截图、限值、偏差、判定原因和修改痕迹。
3. 点击“确认”即电子签名，记录锁定；点击“退回”后回到待提交状态，并向原检验人员
   发送站内通知。
4. 可按天平与日期范围导出已复核记录；未复核记录导出件带“未复核”水印。
5. 维护天平、砝码盒与记录模板。模板修改只影响之后新建记录。
6. 已确认记录不允许直接修改；确需更正时由管理员作废后重新校验。
7. 复核确认人员没有个人二维码；如设备卡需要补打，可进入“设备二维码”按编号查询。

## 6. 检验人员：查看天平档案

检验人员可从左侧“天平档案”进入只读目录，按天平编号、唯一号、科室或参考点查询。
目录展示量程、分度值、参考点、容差、默认砝码盒、设备状态和最近校验记录，并可
继续进入历史曲线或对应设备二维码。

## 7. 管理员

管理员可：

- 新增、编辑、停用、删除账号，重置口令；
- 查询全部任务，重试失败任务，取消排队任务；
- 清理源文件已经缺失的失败、待处理或已取消任务；清理必须填写理由并写审计；
- 作废记录并填写理由；
- 查看、筛选和导出审计日志；
- 配置视频配额、查看存储与运行状态；
- 按视频配额、磁盘可用空间、已有视频数量/平均大小和在用天平数预估可存储时长；
- 触发数据库备份并查看结果；
- 为人员导出身份卡、打印空白记录表。
- 在“账号与角色”批量下载人员卡/设备卡内容清单 CSV，用于核对补印范围。

不能删除审计日志，也不能修改已复核记录。管理员操作同样留痕。

## 8. 查询、曲线、打印与导出

- 记录查询支持天平、日期、检验人员、结论和复核状态筛选。
- 待复核记录可按校验日期和提交日期分别筛选，顶部“通知中心”显示未读消息。
- 历史汇总按日期倒序展示，并为 L1、L2、L3 分别绘制“示值误差（mg）”曲线。
  纵轴根据实测波动自动缩放；小圆点表示每组三次称量，折线表示均值，零线表示标称值。
- 单条和批量正式 PDF 适用于已复核确认记录。单日表按 I1-1 至 I3-3 将示值和测量
  时间分别展开为独立行；周统计按周一至周日展开日期列，并逐项分行。
- 待提交/已提交记录 PDF 带“未复核”水印，已作废记录带“已作废”水印。
- 周统计表直接选择“校验周”。系统自动取该自然周周一至周日并导出 A4 横向 PDF。
- 单条记录、周统计、空白表和操作流程的预览均直接显示服务端最终 PDF；打印和下载
  使用同一文件，不再维护独立的网页模拟版式。
- CSV 使用 UTF-8 BOM，可直接用 Excel 打开。
- 审计日志采用服务端分页；CSV 导出按筛选条件遍历完整结果，不再受单页条数限制。

## 9. 标准操作流程与帮助

左侧导航“操作流程”提供面向用户的标准操作步骤、三类角色要点、二维码/周统计/
曲线阅读说明及常见问题。页面右上角可：

- 下载“标准操作流程 PDF”，用于培训、传阅和打印；
- 打开最终 PDF 预览并使用 PDF 查看器打印。

## 10. 识别能力说明

系统先从多帧搜索显示屏区域，再逐秒抽取视频帧执行本地七段码 OCR，复杂彩色显示屏使用
离线 Tesseract 回退。每个识别值都会保存真实视频帧、显示屏识别框、帧偏移、
识别文本、置信度和稳定段起止时间。点击记录详情中的截图可打开“识别帧核验”，
并直接播放对应视频位置。

若读数缺失、OCR 置信度低或未形成连续 3 秒稳定段，该字段会进入人工核对；
无法识别出任何有效示值时任务进入“待人工处理”。系统不会根据文件名、哈希或
已知样例自动填入读数。

二维码检测支持同帧多个二维码，并可跨多个抽样帧合并人员与设备身份。无法唯一
识别或卡面与登录人员/读数设备冲突时，系统不会生成自动正式记录。清洁、水平调节
和内部校正结果由人工观察确认，不属于自动语音识别范围。

## 11. 遇到问题时

1. 卡面识别失败：检查打印清晰度、反光、折痕和遮挡，必要时重新打印卡片并补拍。
2. 任务待人工处理：查看任务原因；管理员核实原始视频后可执行人工补录并填写理由。
3. PDF 下载失败：确认账号具备导出权限、日期范围有符合状态的记录，并允许浏览器下载。
4. 存储时长不足：在运行状态页查看每日预计新增、平均视频大小和限制因素，再决定扩容
   或调整清理策略。
5. 健康检查失败：查看响应中的 `analyzer`、`pdf` 和 `queue`，确认 FFmpeg、
   Poppler、字体和分析队列均可用。
