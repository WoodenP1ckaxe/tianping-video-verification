# 安全加固说明

本文件记录独立安全审查后的落地情况。系统仍需在客户环境中执行一次正式渗透测试
和恢复演练，不能以本说明替代现场安全验收。

## 已落实

| 审查项 | 处理结果 |
| --- | --- |
| 固定初始口令 | 新库未配置口令时生成随机一次性口令并写入受保护文件；Compose 强制要求 `INITIAL_PASSWORD`；新建/重置账号生成独立临时口令，不再回退到固定值 |
| 口令暴力尝试 | 已知账号连续 5 次失败锁定 10 分钟并写审计；未知账号按来源 IP 在 5 分钟窗口限流；不再使用图片验证码 |
| 账号枚举 | 未知、停用账号和普通口令错误的公开消息统一为“账号或口令错误”；验证码接口不再区分账号存在性 |
| 旧会话撤销 | 用户自行改密时删除同账号其他服务端会话，仅保留当前会话；重置口令删除该账号全部会话 |
| 上传资源消耗 | 增加每用户/全局未完成会话上限、声明临时空间上限、磁盘最低余量、超时会话及孤儿目录清理 |
| 来源 IP 伪造 | 默认使用 socket 地址；只有 `TRUST_PROXY` 明确列出的 IP 或 IPv4 CIDR 才参与转发链解析 |
| 查询审计 | 工作台快照、记录列表、详情、原始视频和识别截图读取按会话节流写入审计 |
| 审计原子性 | 登录失败、登录成功、改密、登出、记录修改/提交/复核/退回/作废、主数据、模板、账号和任务完成等关键变更与审计写入置于同一 SQLite 事务 |
| CSV 公式注入 | 文本单元格去除前导控制字符后，如以 `= + - @` 开头则前置单引号；数值类型保持不变 |
| 内部路径泄露 | API 任务 DTO 不返回绝对路径；分析器媒体错误映射为 4xx/5xx，原始 stderr 和临时路径只写服务端日志 |
| 大文本和极端数值 | 备注限 2000 字符，修改/核对/退回/作废理由限 1000 字符；读数舍入后再次检查有限数与量程上限 |
| 文件流异常 | 静态资源、视频和截图读取绑定流错误处理，单个文件故障不形成未处理异常 |
| 队列崩溃窗口 | 分析结果先复制到记录目录，数据库事务成功后再删除源文件；失败时清理暂存副本并保留可重试源文件 |
| 最小披露 | 非账号管理员的工作台只获得账号 ID、姓名、角色和状态，不获得失败次数、锁定状态、首次改密和最近登录信息 |
| 健康检查 | 同时检查数据库、分析媒体工具、PDF 字体、内置 PDFium 预览和队列；组件缺失返回 503 |
| 正常停机 | 在途任务固定为 `失败/E-SHUTDOWN`，不会在数据库关闭后继续写状态 |
| 输入校验 | 严格校验真实日历日期和分钟时间；拒绝非对象 JSON、非法页码和畸形 URI 编码 |
| 局部更新 | 未提供的字典/砝码盒状态保持不变，避免编辑备注时意外重新启用停用对象 |
| SQLite 备份 | 使用 `VACUUM INTO` 生成一致性快照，备份名称加入短随机后缀避免同分钟冲突 |

## 运行配置

生产代理部署时，例如反向代理位于 `10.10.0.5`：

```dotenv
TRUST_PROXY=10.10.0.5
```

多个代理可配置为逗号分隔的 IP 或 IPv4 CIDR。不得在应用直接暴露给客户端时设置
`TRUST_PROXY=true`。
