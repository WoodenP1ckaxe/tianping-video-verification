# 快速使用说明

## 安装后第一次打开

1. 双击安装包，按图形化向导完成安装。
2. Windows 安装器默认不需要管理员权限，所有运行组件都已包含在安装包中。
3. 安装完成后，控制面板会自动启动服务并打开浏览器。
4. 在控制面板查看一次性初始口令，使用管理员账号 `U000` 登录。
5. 所有账号的初始密码相同，首次登录后必须改成各自的私人密码。

## 初始账号

| 账号 | 角色 |
| --- | --- |
| `U000` | 系统管理员 |
| `U001` / `U002` | 检验人员 |
| `U003` | 复核确认人员 |

## 基本流程

1. 检验人员生成并打印本人二维码；设备二维码由管理员或复核人员打印。
2. 按标准操作流程拍摄视频，并上传 MP4/MOV 文件。
3. 分析完成后核对身份、读数、时间和识别截图。
4. 检验人员提交，再由复核确认人员确认或退回。
5. 管理员定期备份，并按规定导出 PDF/CSV。

## Windows 日常操作

双击“天平校验视频分析系统”打开控制面板：

- “打开系统”：启动服务并打开浏览器。
- “重启服务”：服务异常时重启。
- “数据目录”：打开数据库、视频、截图和备份所在目录。
- “使用说明”：打开本安装包内的完整快速指南。
- “运行诊断”：检查 Node、FFmpeg、字体、端口和健康状态。

关闭浏览器或控制面板不会停止系统。默认只允许本机访问。

## Linux 日常操作

无 root 用户安装：

```bash
~/.local/share/tianping-video-verification/installation/control/service.sh open
```

系统级安装：

```bash
/opt/tianping-video-verification/control/service.sh open
```

将 `open` 换成 `status`、`restart` 或 `stop` 可管理服务。

## 数据与卸载

卸载程序默认不会删除数据库、视频、截图、PDF 或备份。正式重装或升级前仍应先执行备份。

完整角色操作说明见 `USER_GUIDE.md`；部署和故障排查见 `DEPLOYMENT.md`。
